### Further reading

1. [**Speed Up Feature Engineering with Robusta**](https://eng.snap.com/speed-up-feature-engineering) by Snap

   Declarative YAML feature definitions, associative-commutative aggregations, Lambda architecture on Spark, Iceberg & Aerospike, pre-aggregated blocks.

2. [**Michelangelo Palette**](https://www.infoq.com/presentations/michelangelo-palette-uber/) by Uber, InfoQ talk

   Uber's ML platform with Palette feature store, from infrastructure to applications.

3. [**Distributed Time Travel for Feature Generation**](https://netflixtechblog.com/distributed-time-travel-for-feature-generation-389cccdd3907) by Netflix

   DeLorean system: snapshot online microservice states, Time Travel API reconstructing objects, shared feature encoders.

4. [**Feast**](https://feast.dev) - Feature Store Framework

   Most widely adopted OSS feature storage library, API design example for reusability in different domains.

5. [**Designing Data-Intensive Applications**](https://www.oreilly.com/library/view/designing-data-intensive-applications/9781098119058/) by Martin Kleppmann (O'Reilly, 2017 / 2026)
   
   Of course it's here! One of the best system design books, applicable to modern ML; second edition is adapting to trends.
